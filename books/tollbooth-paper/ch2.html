1. Ma trận đa thức đặc trưng (Characteristic Matrix Polynomial)

Từ quan hệ truy hồi (eq 12) ở Chương 1, phương pháp spectral expansion đòi hỏi ta tìm trị riêng và vector riêng của ma trận đa thức:

{% include components/box-start.html type="formula" title='Ma trận đa thức đặc trưng Q(x)' %} \[ Q(x) = A_0 + A_1 x + A_2 x^2 + A_3 x^3 \]

Đây là đa thức bậc 3 theo \(x\) với hệ số là ma trận \(3 \times 3\). Trị riêng \(x\) và vector riêng trái \(\boldsymbol{\psi}(x)\) thỏa mãn (eq 16):

\[ \det[Q(x)] = 0, \quad \boldsymbol{\psi}(x)\, Q(x) = \mathbf{0} \] {% include components/box-end.html %}

Thay các ma trận \(A_0, A_1, A_2, A_3\) từ eq 11:

\[ Q(x) = \begin{bmatrix} \lambda - (\lambda+\mu_2)x & 0 & \mu_2 x^3 \\ 0 & \lambda - (\mu_1+\lambda)x + \mu_1 x^2 & 0 \\ \mu_1 x & \mu_2 x^2 & \lambda - (\mu_1+\mu_2+\lambda)x \end{bmatrix} \]

2. Trị riêng (Eigenvalues)

Khai triển \(\det[Q(x)] = 0\), bài báo chỉ ra (eq 17):

{% include components/box-start.html type="formula" title='Đa thức đặc trưng bậc 5 (eq 17)' %} \[ \begin{aligned} \det[Q(x)] &= (x - 1)\big(ax^4 + bx^3 + cx^2 + dx + e\big) \tag{17} \end{aligned} \]

với các hệ số:

\[ \begin{aligned} a &= \mu_1\mu_2(2\lambda + \mu_1 + \mu_2), \\ b &= \mu_1\mu_2(\mu_1 + \mu_2), \\ c &= -\lambda\big[(\lambda + \mu_1)^2 + (2\lambda + 3\mu_1)\mu_2 + \mu_2^2\big], \\ d &= 2\lambda^2(\lambda + \mu_1 + \mu_2), \\ e &= -\lambda^3. \end{aligned} \] {% include components/box-end.html %}

Cấu trúc: Đa thức bậc 5 = \((x-1)\) × đa thức bậc 4. Nghiệm \(x = 1\) ứng với điều kiện chuẩn hóa. Bốn nghiệm còn lại \(r_1, r_2, r_3, r_4\) từ phương trình bậc 4.

3. Giải phương trình bậc 4 (Quartic Formula)

Bài báo sử dụng công thức giải phương trình bậc 4 của Borwein & Erdélyi (1995) để tìm tường minh 4 nghiệm \(r_1, r_2, r_3, r_4\) của \(ax^4 + bx^3 + cx^2 + dx + e = 0\).

{% include components/box-start.html type="formula" title='Bốn trị riêng r₁, r₂, r₃, r₄ (eqs 18–21)' %} \[ \begin{aligned} r_1 &= -\frac{b}{4a} - Y - \frac{1}{2}\sqrt{-4Y^2 - 2p + \frac{q}{Y}} \tag{18} \\[6pt] r_2 &= -\frac{b}{4a} - Y + \frac{1}{2}\sqrt{-4Y^2 - 2p + \frac{q}{Y}} \tag{19} \\[6pt] r_3 &= -\frac{b}{4a} + Y + \frac{1}{2}\sqrt{-4Y^2 - 2p - \frac{q}{Y}} \tag{20} \\[6pt] r_4 &= -\frac{b}{4a} + Y - \frac{1}{2}\sqrt{-4Y^2 - 2p - \frac{q}{Y}} \tag{21} \end{aligned} \] {% include components/box-end.html %}

Các đại lượng trung gian (eqs 22–27):

{% include components/box-start.html type="formula" title='Các hệ số trung gian Δ₀, Δ₁, X, p, q, Y (eqs 22–27)' %} \[ \begin{aligned} \Delta_0 &= c^2 - 3bd + 12ae \tag{22} \\[4pt] \Delta_1 &= 2c^3 - 9bcd + 27b^2 e + 27ad^2 - 72ace \tag{23} \\[4pt] X &= \left(\frac{\Delta_1 + (\Delta_1^2 - 4\Delta_0^3)^{1/2}}{2}\right)^{1/3} \tag{24} \\[4pt] p &= \frac{8ac - 3b^2}{8a^2} \tag{25} \\[4pt] q &= \frac{b^3 - 4abc + 8a^2 d}{8a^3} \tag{26} \\[4pt] Y &= \left(\frac{1}{2}\left(-\frac{2p}{3} + \frac{1}{3a}\left(X + \frac{\Delta_0}{X}\right)\right)\right)^{1/2} \tag{27} \end{aligned} \] {% include components/box-end.html %}

Tại sao giải được tường minh? Ma trận pha kích thước \(3 \times 3\) cho đa thức đặc trưng bậc 5, phân tích thành \((x-1)\) × bậc 4. Phương trình bậc 4 có công thức nghiệm tường minh. Từ bậc 5 trở lên, không tồn tại công thức tổng quát (định lý Abel–Ruffini).

4. Proposition 2 (Three eigenvalues inside the unit circle)

{% include components/box-start.html type="theorem" title='Proposition 2' %}

Các trị riêng dùng để tính xác suất dừng là \(r_2\), \(r_3\) và \(r_4\).

{% include components/box-end.html %}

Giải thích: Từ eq 17, \(Q(x)\) có 5 trị riêng: \(r_0 = 1\) (từ nhân tử \(x-1\)) và \(r_1, r_2, r_3, r_4\) (từ phương trình bậc 4).

Bài báo chỉ ra rằng \(Y > 0\), \(p < 0\), \(q > 0\), và từ eqs 18–21, \(|r_1|\) là giá trị lớn nhất trong \(\{|r_1|, |r_2|, |r_3|, |r_4|\}\). Mặt khác, từ Section 3.2, \(Q(x)\) chỉ có đúng 3 trị riêng trong đường tròn đơn vị, do đó:

  • \(|r_1| > 1\) (ngoài đường tròn đơn vị, không dùng).
  • \(|r_2| < 1\), \(|r_3| < 1\), \(|r_4| < 1\) (trong đường tròn đơn vị, dùng cho spectral expansion).
  • \(r_0 = 1\) nằm trên đường tròn đơn vị.

Remark 1 (bài báo): Đặt \(x_1 = r_2\), \(x_2 = r_3\), \(x_3 = r_4\) để dùng trong công thức spectral expansion (eq 15).

5. Vector riêng (Eigenvectors)

Với mỗi trị riêng \(x_i\) (\(i = 1, 2, 3\)), vector riêng trái tương ứng \(\boldsymbol{\psi}_i(x_i)\) có 3 thành phần và thỏa mãn \(\boldsymbol{\psi}_i Q(x_i) = \mathbf{0}\).

{% include components/box-start.html type="formula" title='Vector riêng ψᵢ(x) — 3 thành phần (eq 28)' %}

Từ eq 16, giải hệ phương trình tuyến tính, ta được:

\[ \boldsymbol{\psi}_i(x) = \left[1,\;\; \frac{\mu_2 x(\lambda x - \lambda + \mu_2)}{\mu_1(\lambda x - \lambda + \mu_1 x)},\;\; \frac{\lambda x + \mu_2 x - \lambda}{\mu_1 x}\right] \tag{28} \]

Vector riêng được chuẩn hóa sao cho thành phần đầu tiên bằng 1.

{% include components/box-end.html %}

6. Hệ số a₁, a₂, a₃ (Coefficients: Proposition 3)

Xác suất dừng tại mức \(j \geq 2\) được biểu diễn (eq 15):

\[ \mathbf{v}_j = \sum_{i=1}^{3} a_i\, x_i^{j-2}\, \boldsymbol{\psi}_i(x_i), \quad j \geq 2 \]

Cần xác định 3 hệ số \(a_1, a_2, a_3\) từ điều kiện biên và chuẩn hóa.

{% include components/box-start.html type="theorem" title='Proposition 3 (eqs 29–31)' %}

Ba hệ số được cho bởi:

\[ a_1 = \frac{\lambda^2 \mu_1(-1+x_1)x_1\big(\lambda(-1+x_1)+\mu_1 x_1\big)(-1+x_2)(-1+x_3)}{G} \tag{29} \] \[ a_2 = \frac{\lambda^2 \mu_1(x_1-1)(x_2-1)x_2\big(\lambda(x_2-1)+\mu_1 x_2\big)(1-x_3)}{G} \tag{30} \] \[ a_3 = \frac{\lambda^2 \mu_1(1-x_1)(x_2-1)(1-x_3)x_3\big(\lambda(x_3-1)+\mu_1 x_3\big)}{G} \tag{31} \]

trong đó \(G = (x_1 - x_2)(x_1 - x_3)(\mu_1^2(\mu_1+\mu_2)(x_1-1)(x_3-1)(x_2-1) + \cdots)\) là biểu thức dài (xem bài báo gốc).

{% include components/box-end.html %}

Chứng minh (Proposition 3): Thay (15) và (28) vào phương trình cân bằng (1)–(6) và điều kiện chuẩn hóa (10). Trong 6 phương trình (1)–(6), chỉ 5 là độc lập. Từ đó, cần 6 phương trình tuyến tính (5 balance + 1 normalization) để xác định 6 ẩn: \(\pi_{0,0}\), \(\pi_{1,1}\), \(\pi_{2,1}\), \(a_1\), \(a_2\), \(a_3\). Ba hệ số được xác định duy nhất cùng với \(\pi_{0,0}\), \(\pi_{1,1}\), \(\pi_{2,1}\). \(\square\)

7. Xác suất trạng thái dừng (Steady-State Probabilities)

{% include components/box-start.html type="definition" title='Xác suất trạng thái dừng (eqs 32–34)' %}

Xác suất hệ trống (eq 32):

\[ \pi_{0,0} = \frac{(\lambda + \mu_2)(\mu_2 \pi_{1,2} + \mu_1 \pi_{2,1}) + \mu_2(\mu_2 \pi_{1,3} + \mu_1 \pi_{2,2})}{\lambda^2} \tag{32} \]

Xác suất tại mức 1 (eqs 33–34):

\[ \pi_{1,1} = \frac{\mu_2 \pi_{1,2} + \mu_2 \pi_{1,3} + \mu_1 \pi_{2,1} + \mu_1 \pi_{2,2}}{\lambda} \tag{33} \] \[ \pi_{2,1} = \frac{\mu_2 \pi_{3,2}}{\mu_1 + \lambda} \tag{34} \]

Xác suất tại mức \(j \geq 2\):

\[ [\pi_{1,j},\; \pi_{2,j},\; \pi_{3,j}] = \sum_{i=1}^{3} a_i\, x_i^{j-2}\, \boldsymbol{\psi}_i(x_i) \] {% include components/box-end.html %}

8. Công thức hiệu năng (Performance Measures)

{% include components/box-start.html type="formula" title='Số khách trung bình L (eq 35)' %} \[ L = \pi_{1,1} + \pi_{2,1} + \sum_{j=2}^{\infty} j\,\mathbf{v}_j\,\mathbf{e} = \pi_{1,1} + \pi_{2,1} + \sum_{i=1}^{3} a_i \frac{2 - x_i}{(1 - x_i)^2}\,\boldsymbol{\psi}_i(x_i)\,\mathbf{e} \tag{35} \]

với \(\mathbf{e} = [1, 1, 1]^T\).

{% include components/box-end.html %} {% include components/box-start.html type="formula" title='Thời gian chờ W và xác suất blocking' %}

Thời gian chờ trung bình \(W\) — theo Little's law (Little, 1961):

\[ W = \frac{L}{\lambda} \]

Xác suất bị chặn \(P_b\) — bài báo ghi nhận rằng xác suất khách bị chặn bởi server 2 "can easily be computed" từ phân phối dừng đã tìm được.

{% include components/box-end.html %} {% include components/box-start.html type="summary" title='Tóm tắt chương' %}
  • \(\det[Q(x)] = (x-1)(ax^4+bx^3+cx^2+dx+e)\) — đa thức bậc 5, phân tích thành \((x-1)\) × bậc 4 (eq 17).
  • 5 trị riêng: \(r_0 = 1\) (trên), \(r_1\) (ngoài), \(r_2, r_3, r_4\) (trong đường tròn đơn vị).
  • Proposition 2: dùng \(r_2, r_3, r_4\) cho spectral expansion.
  • Vector riêng \(\boldsymbol{\psi}_i\) có 3 thành phần (eq 28).
  • Hệ số \(a_1, a_2, a_3\) từ Proposition 3 (eqs 29–31).
  • Xác suất dừng dạng đóng: \(\mathbf{v}_j = \sum a_i x_i^{j-2}\boldsymbol{\psi}_i\).
  • \(L\) từ eq 35, \(W = L/\lambda\).
