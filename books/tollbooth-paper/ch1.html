1. Mô hình tollbooth (Tollbooth Model)

Xét hệ thống hàng đợi tollbooth gồm hai server đặt nối tiếp (tandem). Mô hình này dùng để mô tả trạm thu phí đường cao tốc, nơi hai nhân viên thu phí phục vụ khách hàng tại hai quầy đặt liên tiếp (Section 3.1, bài báo).

{% include components/box-start.html type="definition" title='Mô hình hàng đợi Tollbooth' %}

Hệ thống gồm:

  • Dòng đến: Khách hàng đến theo quá trình Poisson với tốc độ \(\lambda\).
  • Server 1: Thời gian phục vụ phân phối mũ với tham số \(\mu_1\).
  • Server 2: Thời gian phục vụ phân phối mũ với tham số \(\mu_2\).
  • Bộ đệm: Hàng đợi trước server 1 có dung lượng vô hạn. Giữa hai server không có bộ đệm.
{% include components/box-end.html %}

Hệ thống được đặc trưng bởi 5 quy tắc phục vụ sau (trích Section 3.1):

  1. Mỗi khách chỉ được phục vụ bởi một server. Hai server có thể đồng thời rảnh nếu không có khách chờ trong bộ đệm.
  2. FIFO (First-In-First-Out): thứ tự phục vụ theo thứ tự đến tại mỗi server.
  3. Blocking khi rời: Khách hoàn thành phục vụ tại server 1 không thể rời hệ thống nếu server 2 đang bận. Khách bị chặn (blocked) và phải đợi cho đến khi khách tại server 2 hoàn thành — khi đó hai khách cùng rời hệ thống. Server 1 lúc này rảnh nhưng không thể nhận khách mới vì vị trí phục vụ bị chiếm bởi khách bị chặn.
  4. Server 2 không nhận từ bộ đệm: Nếu server 2 rảnh nhưng server 1 đang bận, server 2 không thể phục vụ khách từ bộ đệm. Khách đang được phục vụ bởi server 1 chặn sự di chuyển của khách từ bộ đệm.
  5. Cả hai rảnh → vào server 2: Nếu cả hai server đều rảnh, khách đến được phục vụ bởi server 2.
{% include components/box-start.html type="summary" title='Điểm khác biệt quan trọng' %}

Quy tắc 3 tạo ra hiện tượng rời đôi (double departure): khi server 2 hoàn thành và có khách bị chặn tại server 1, hai khách cùng rời hệ thống. Đây là lý do chuỗi Markov có dạng GI/M/1-type (chuyển xuống 2 mức) thay vì QBD chuẩn.

{% include components/box-end.html %}

Ký hiệu chính:

  • \(\lambda\): tốc độ đến (arrival rate)
  • \(\mu_1\): tốc độ phục vụ của server 1
  • \(\mu_2\): tốc độ phục vụ của server 2
  • \(1/\lambda\): thời gian trung bình giữa hai lần đến
  • \(1/\mu_k\): thời gian phục vụ trung bình của server \(k\)

2. Chuỗi Markov liên tục (CTMC) (Continuous-Time Markov Chain)

Gọi \(J(t)\) là số khách hàng trong hệ thống tại thời điểm \(t\). Gọi \(I^*(t)\) là trạng thái của hai server tại thời điểm \(t\), nhận giá trị trong \(\{0, 1, 2, 3\}\) theo Table 1 của bài báo:

{% include components/box-start.html type="definition" title='Trạng thái server I*(t) — Table 1' %}
\(I^*(t)\)Server 1Server 2Mô tả
0Rảnh (Idle)Rảnh (Idle)Cả hai server đều rảnh
1Rảnh (Idle)Bận (Busy)Chỉ server 2 đang phục vụ
2Bận (Busy)Rảnh (Idle)Chỉ server 1 đang phục vụ
3Bận (Busy)Bận (Busy)Cả hai server đều bận

Lưu ý: \(I^* = 1\) bao gồm cả trường hợp server 1 "rảnh" nhưng vị trí bị chiếm bởi khách bị chặn (blocked customer).

{% include components/box-end.html %}

Hệ thống được mô tả bởi CTMC \(\{I^*(t), J(t)\}\) trên không gian trạng thái:

\[ S = \{(0, 0)\} \cup \{(1, 1)\} \cup \{(2, 1)\} \cup \{(k, l) : k = 1, 2, 3;\; l \geq 2\} \]

Giải thích:

  • Mức 0: Chỉ có trạng thái \((0, 0)\) — hệ trống, cả hai server rảnh.
  • Mức 1: Hai trạng thái \((1, 1)\) và \((2, 1)\) — một khách đang ở server 2 hoặc server 1. Không thể có \((3, 1)\) vì chỉ 1 khách thì không thể cả hai server đều bận.
  • Mức \(l \geq 2\): Ba trạng thái \((1, l)\), \((2, l)\), \((3, l)\) — server có thể ở trạng thái 1, 2, hoặc 3. Trạng thái \((0, l)\) không xảy ra vì có khách trong hệ thì ít nhất một server phải bận.
{% include components/review-start.html title='Ôn tập: CTMC (từ Chuỗi Markov, Ch. 5)' %}

Chuỗi Markov thời gian liên tục là quá trình ngẫu nhiên \(\{X(t) : t \geq 0\}\) sao cho:

  • Thời gian ở mỗi trạng thái phân phối mũ (exponential).
  • Khi rời trạng thái, chuyển sang trạng thái mới theo xác suất cố định.
  • Tính chất Markov: tương lai chỉ phụ thuộc hiện tại, không phụ thuộc quá khứ.

Xem chi tiết: Chuỗi Markov, Chương 5.

{% include components/review-end.html %}

3. Quy tắc vận hành (Operating Rules)

Từ 5 quy tắc phục vụ, bài báo suy ra 4 quy tắc đến (arrival rules) sau:

{% include components/box-start.html type="definition" title='Quy tắc khi khách đến' %}
  • Nếu \(I^*(t) = 0\) (cả hai rảnh): khách được phục vụ bởi server 2.
  • Nếu \(J(t) = 1\) và server 1 đang bận (\(I^* = 2\)): khách chờ trong bộ đệm.
  • Nếu \(J(t) = 1\) và server 2 đang bận (\(I^* = 1\)): khách được phục vụ bởi server 1.
  • Nếu \(J(t) \geq 2\): khách vào bộ đệm.
{% include components/box-end.html %}

Giải thích quy tắc 2 & 3 (khi \(J = 1\)):

  • Nếu \(I^* = 2\) (S1 bận, S2 rảnh): S2 rảnh nhưng không thể nhận khách từ bộ đệm vì khách tại S1 chặn sự di chuyển. Khách mới phải chờ.
  • Nếu \(I^* = 1\) (S1 rảnh, S2 bận): S1 rảnh và có thể nhận khách. Khách mới vào S1.
{% include components/box-start.html type="summary" title='Quy tắc rời' %}

Khi server hoàn thành phục vụ, có hai kịch bản:

  • Rời đơn: Server 1 hoàn thành và server 2 rảnh (không bị chặn) → 1 khách rời.
  • Rời đôi: Server 2 hoàn thành và có khách bị chặn tại server 1 → 2 khách cùng rời. Sau đó, nếu bộ đệm có ≥ 2 khách, cả hai server nhận khách mới (S2 trước theo quy tắc 5).
{% include components/box-end.html %}

4. Sơ đồ tốc độ chuyển (Transition Rate Diagram)

Sơ đồ dưới đây mô tả các tốc độ chuyển chính giữa các trạng thái (Fig. 1 trong bài báo). Không gian trạng thái được chia thành các mức (level) theo số khách \(J\).

Mức 0 → Mức 1:

  • \((0,0) \xrightarrow{\lambda} (1,1)\): Khách đến khi hệ trống → vào server 2 (quy tắc 5).

Mức 1 (nội bộ & liên mức):

  • \((1,1) \xrightarrow{\mu_2} (0,0)\): Server 2 xong → khách rời, hệ trống.
  • \((1,1) \xrightarrow{\lambda} (3,2)\): Khách đến, S2 bận → vào S1 → cả hai bận, 2 khách.
  • \((2,1) \xrightarrow{\mu_1} (0,0)\): Server 1 xong, S2 rảnh (không bị chặn) → khách rời.
  • \((2,1) \xrightarrow{\lambda} (2,2)\): Khách đến, S1 bận → vào bộ đệm.

Mức \(l \geq 2\) — Chuyển trong cùng mức (ma trận \(A_1\)):

  • \((3,l) \xrightarrow{\mu_1} (1,l)\): S1 xong nhưng S2 bận → khách bị chặn.

Mức \(l \geq 2\) — Chuyển lên 1 mức (ma trận \(A_0\)):

  • \((k,l) \xrightarrow{\lambda} (k,l{+}1)\): Khách đến → vào bộ đệm, trạng thái server không đổi.

Mức \(l \geq 2\) — Chuyển xuống 1 mức (ma trận \(A_2\)):

  • \((3,l) \xrightarrow{\mu_2} (2,l{-}1)\): S2 xong → 1 khách rời, S1 vẫn bận.
  • \((2,l) \xrightarrow{\mu_1} (3,l{-}1)\): S1 xong, không bị chặn → 1 khách rời, cả hai rảnh, 2 khách từ bộ đệm lấp cả hai server → trạng thái 3.

Mức \(l \geq 2\) — Chuyển xuống 2 mức (ma trận \(A_3\)):

  • \((1,l) \xrightarrow{\mu_2} (3,l{-}2)\): S2 xong + khách bị chặn tại S1 → 2 khách cùng rời, cả hai rảnh, 2 khách từ bộ đệm lấp cả hai server.

5. Ma trận tốc độ chuyển (Transition Rate Matrices)

Đặt \(\mathbf{v}_j = [\pi_{1,j},\; \pi_{2,j},\; \pi_{3,j}]\) là vector xác suất dừng tại mức \(j \geq 2\). Các ma trận tốc độ chuyển có kích thước \(3 \times 3\), ứng với 3 pha \(I^* \in \{1, 2, 3\}\) (eq 11):

{% include components/box-start.html type="formula" title='Ma trận tốc độ chuyển A₀, A₁, A₂, A₃ (eq 11)' %}

Chuyển lên 1 mức (thêm khách):

\[ A_0 = \begin{bmatrix} \lambda & 0 & 0 \\ 0 & \lambda & 0 \\ 0 & 0 & \lambda \end{bmatrix} \]

Chuyển trong cùng mức:

\[ A_1 = \begin{bmatrix} -\lambda - \mu_2 & 0 & 0 \\ 0 & -\mu_1 - \lambda & 0 \\ \mu_1 & 0 & -\mu_1 - \mu_2 - \lambda \end{bmatrix} \]

Chuyển xuống 1 mức (1 khách rời):

\[ A_2 = \begin{bmatrix} 0 & 0 & 0 \\ 0 & 0 & \mu_1 \\ 0 & \mu_2 & 0 \end{bmatrix} \]

Chuyển xuống 2 mức (2 khách cùng rời):

\[ A_3 = \begin{bmatrix} 0 & 0 & \mu_2 \\ 0 & 0 & 0 \\ 0 & 0 & 0 \end{bmatrix} \] {% include components/box-end.html %}

Đọc ma trận: Hàng = trạng thái đi, cột = trạng thái đến. Ví dụ \(A_1[3,1] = \mu_1\): từ trạng thái 3 (cả hai bận), S1 hoàn thành (tốc độ \(\mu_1\)), chuyển sang trạng thái 1 (S1 rảnh/bị chặn, S2 bận) mà không thay đổi số khách.

\(A_3[1,3] = \mu_2\): từ trạng thái 1 (S1 rảnh/bị chặn, S2 bận), S2 hoàn thành → 2 khách rời (rời đôi) → cả hai rảnh → 2 khách từ bộ đệm lấp cả hai server → trạng thái 3.

6. Phương trình cân bằng (Balance Equations)

Tại trạng thái dừng, tốc độ vào = tốc độ ra cho mỗi trạng thái. Gọi \(\pi_{i,j} = \lim_{t \to \infty} \Pr(I^*(t) = i,\; J(t) = j)\) là xác suất trạng thái dừng. Bài báo đưa ra 9 phương trình cân bằng (eqs 1–9):

Nguyên tắc đọc: vế trái = tốc độ ra (rời trạng thái), vế phải = tốc độ vào (đến trạng thái). Mỗi số hạng ở vế phải tương ứng một "nguồn" có thể chuyển vào trạng thái đang xét.

{% include components/box-start.html type="formula" title='Phương trình biên: trạng thái tại mức 0 và 1 (eqs 1–6)' %}

Trạng thái \((0,0)\) — hệ trống:

\[ \pi_{0,0}\,\lambda = (\pi_{1,1} + \pi_{1,2})\,\mu_2 + \pi_{2,1}\,\mu_1 \tag{1} \]

Ra: khách đến (\(\lambda\)). Vào từ: \((1,1)\) khi S2 xong, 1 khách rời; \((1,2)\) khi S2 xong, 2 khách rời đôi; \((2,1)\) khi S1 xong, 1 khách rời.

Trạng thái \((1,1)\) — S2 bận, 1 khách:

\[ \pi_{1,1}(\mu_2 + \lambda) = \pi_{0,0}\,\lambda + \pi_{1,3}\,\mu_2 + \pi_{2,2}\,\mu_1 \tag{2} \]

Ra: S2 xong (\(\mu_2\)) hoặc khách đến (\(\lambda\)). Vào từ: \((0,0)\) khi khách đến → vào S2; \((1,3)\) khi S2 xong → 2 rời đôi → 1 khách còn → vào S2; \((2,2)\) khi S1 xong → 1 rời → 1 khách còn → vào S2.

Trạng thái \((2,1)\) — S1 bận, 1 khách:

\[ \pi_{2,1}(\mu_1 + \lambda) = \pi_{3,2}\,\mu_2 \tag{3} \]

Chỉ có 1 nguồn vào: từ \((3,2)\) khi S2 xong → 1 khách rời → S1 vẫn bận.

Trạng thái \((1,2)\) — S1 bị chặn + S2 bận, 2 khách:

\[ \pi_{1,2}(\mu_2 + \lambda) = \pi_{3,2}\,\mu_1 \tag{4} \]

Chỉ có 1 nguồn vào: từ \((3,2)\) khi S1 xong → bị chặn (vì S2 bận).

Trạng thái \((2,2)\) — S1 bận, S2 rảnh, 2 khách:

\[ \pi_{2,2}(\mu_1 + \lambda) = \pi_{2,1}\,\lambda + \pi_{3,3}\,\mu_2 \tag{5} \]

Vào từ: \((2,1)\) khi khách đến → vào bộ đệm; \((3,3)\) khi S2 xong → 1 rời → S1 vẫn bận.

Trạng thái \((3,2)\) — cả hai bận, 2 khách:

\[ \pi_{3,2}(\mu_2 + \mu_1 + \lambda) = \pi_{1,1}\,\lambda + \pi_{2,3}\,\mu_1 + \pi_{1,4}\,\mu_2 \tag{6} \]

Vào từ: \((1,1)\) khi khách đến → vào S1 → cả hai bận; \((2,3)\) khi S1 xong → 1 rời → cả hai rảnh → 2 khách bộ đệm lấp cả hai; \((1,4)\) khi S2 xong → 2 rời đôi → cả hai rảnh → 2 khách bộ đệm lấp cả hai.

{% include components/box-end.html %} {% include components/box-start.html type="formula" title='Phương trình lặp: trạng thái tại mức j ≥ 3 (eqs 7–9)' %}

Từ mức 3 trở đi, phương trình có dạng lặp lại — đây là cấu trúc GI/M/1-type:

Trạng thái \((1,j)\) — S1 bị chặn + S2 bận:

\[ \pi_{1,j}(\mu_2 + \lambda) = \pi_{1,j-1}\,\lambda + \pi_{3,j}\,\mu_1 \tag{7} \]

Vào từ: \((1,j{-}1)\) khi khách đến → bộ đệm; \((3,j)\) khi S1 xong → bị chặn.

Trạng thái \((2,j)\) — S1 bận, S2 rảnh:

\[ \pi_{2,j}(\mu_1 + \lambda) = \pi_{2,j-1}\,\lambda + \pi_{3,j+1}\,\mu_2 \tag{8} \]

Vào từ: \((2,j{-}1)\) khi khách đến → bộ đệm; \((3,j{+}1)\) khi S2 xong → 1 rời → S1 vẫn bận.

Trạng thái \((3,j)\) — cả hai bận:

\[ \pi_{3,j}(\mu_2 + \mu_1 + \lambda) = \pi_{3,j-1}\,\lambda + \pi_{2,j+1}\,\mu_1 + \pi_{1,j+2}\,\mu_2 \tag{9} \]

Vào từ: \((3,j{-}1)\) khi khách đến → bộ đệm; \((2,j{+}1)\) khi S1 xong → 1 rời → cả hai rảnh → 2 từ bộ đệm lấp cả hai; \((1,j{+}2)\) khi S2 xong → 2 rời đôi → cả hai rảnh → 2 từ bộ đệm lấp cả hai.

{% include components/box-end.html %}

Điều kiện chuẩn hóa (eq 10):

\[ \pi_{0,0} + \pi_{1,1} + \pi_{2,1} + \sum_{j=2}^{\infty} (\pi_{1,j} + \pi_{2,j} + \pi_{3,j}) = 1 \tag{10} \] {% include components/box-start.html type="summary" title='Cấu trúc của 9 phương trình' %}
  • Eqs 1–6 (biên): cho các trạng thái tại mức 0, 1 và 2. Mỗi phương trình có dạng riêng vì các mức thấp có ít trạng thái hơn.
  • Eqs 7–9 (lặp): cho mức \(j \geq 3\). Cùng một dạng lặp lại ở mọi mức — đây chính là cấu trúc cho phép dùng spectral expansion.
  • Trong 6 phương trình biên (1)–(6), chỉ 5 là độc lập (bài báo). Kết hợp với chuẩn hóa (10), ta có đủ phương trình để xác định tất cả các ẩn.
{% include components/box-end.html %}

7. Điều kiện ổn định (Stability Condition)

{% include components/box-start.html type="theorem" title='Proposition 1 — Điều kiện ổn định (eq 13)' %}

CTMC \(\{I^*(t), J(t)\}\) ổn định (tồn tại phân phối dừng) khi và chỉ khi:

\[ \lambda < \frac{2\mu_1 \mu_2 (\mu_1 + \mu_2)}{\mu_1^2 + \mu_1 \mu_2 + \mu_2^2} \tag{13} \] {% include components/box-end.html %}

Chứng minh (Proposition 1, bài báo): Áp dụng Theorem 1.7.1 (eq 1.7.11) trong sách Neuts (1981), CTMC dạng GI/M/1-type ổn định khi và chỉ khi:

\[ \boldsymbol{\pi} A_0 \mathbf{e} < \boldsymbol{\pi} A_2 \mathbf{e} + 2\boldsymbol{\pi} A_3 \mathbf{e} \tag{14} \]

trong đó \(\boldsymbol{\pi} A = \mathbf{0}\), \(A = A_0 + A_1 + A_2 + A_3\), \(\boldsymbol{\pi}\mathbf{e} = 1\), \(\mathbf{e}^T = [1, 1, 1]\). Nghiệm:

\[ \boldsymbol{\pi} = \frac{1}{\mu_1^2 + \mu_1\mu_2 + \mu_2^2} \begin{bmatrix} \mu_1^2, & \mu_2^2, & \mu_1\mu_2 \end{bmatrix} \]

Thay \(\boldsymbol{\pi}\), \(A_0\), \(A_2\), \(A_3\) vào (14), ta được (13). \(\square\)

{% include components/example-start.html title='Ví dụ: Kiểm tra điều kiện ổn định' %}

Cho \(\mu_1 = 2\), \(\mu_2 = 3\) (khách/phút). Ngưỡng ổn định:

\[ \frac{2 \cdot 2 \cdot 3 \cdot (2 + 3)}{2^2 + 2 \cdot 3 + 3^2} = \frac{2 \cdot 6 \cdot 5}{4 + 6 + 9} = \frac{60}{19} \approx 3{,}16 \text{ khách/phút} \]

Hệ ổn định khi \(\lambda < 3{,}16\). Nếu \(\lambda = 3\): ổn định. Nếu \(\lambda = 4\): không ổn định.

{% include components/example-end.html %}

8. Quá trình GI/M/1-type & Spectral expansion (GI/M/1-type & Spectral Expansion)

Từ các phương trình cân bằng (7)–(9), ta rút ra quan hệ truy hồi cho \(\mathbf{v}_j\) (eq 12):

{% include components/box-start.html type="formula" title='Quan hệ truy hồi GI/M/1-type (eq 12)' %} \[ \mathbf{v}_{j-1} A_0 + \mathbf{v}_j A_1 + \mathbf{v}_{j+1} A_2 + \mathbf{v}_{j+2} A_3 = \mathbf{0}, \quad j \geq 3 \tag{12} \]

Đây là quá trình GI/M/1-type (không phải QBD chuẩn) vì có ma trận \(A_3\) — chuyển xuống 2 mức do hiện tượng rời đôi.

{% include components/box-end.html %}

Trong quá trình QBD chuẩn, chỉ có \(A_0\), \(A_1\), \(A_2\) (block-tridiagonal). Ở đây, ma trận \(A_3\) khiến cấu trúc là block-pentadiagonal theo nghĩa rộng.

{% include components/box-start.html type="definition" title='Phương pháp Spectral Expansion' %}

Đặt ma trận đa thức đặc trưng (eq 15–16):

\[ Q(x) = A_0 + A_1 x + A_2 x^2 + A_3 x^3 \]

Theo Chakka & Do (2007), nghiệm spectral expansion có dạng:

\[ \mathbf{v}_j = \sum_{i=1}^{3} a_i x_i^{j-2}\, \boldsymbol{\psi}_i(x_i), \quad j \geq 2 \tag{15} \]

trong đó:

  • \(x_i\) là trị riêng (eigenvalue) nằm trong đường tròn đơn vị (\(|x_i| < 1\)).
  • \(\boldsymbol{\psi}_i(x_i)\) là vector riêng trái (left eigenvector) tương ứng, có 3 thành phần.
  • \(a_i\) là hệ số xác định bởi điều kiện biên.

Trị riêng và vector riêng thỏa mãn (eq 16):

\[ \det[Q(x_i)] = 0, \quad \boldsymbol{\psi}_i(x_i)\, Q(x_i) = \mathbf{0}, \quad i = 1, 2, 3 \tag{16} \] {% include components/box-end.html %}

So sánh với QBD chuẩn: Nếu là QBD, \(Q(x) = A_0 + A_1 x + A_2 x^2\) (bậc 2, ma trận \(2 \times 2\)), cho đa thức đặc trưng bậc 4 với 2 trị riêng trong đường tròn đơn vị. Ở đây, \(Q(x)\) bậc 3, ma trận \(3 \times 3\), cho đa thức đặc trưng bậc 5 với 3 trị riêng — vừa đủ cho ma trận pha kích thước 3. Chi tiết xem Chương 2: Lời giải dạng đóng.
