1. Thiết lập thực nghiệm (Experimental Setup)

Bài báo khảo sát hiệu năng hệ thống với thời gian phục vụ trung bình \(1/\mu_1\) và \(1/\mu_2\) nhận các giá trị 15, 25, 30, 50 giây — đây là "typical values measured at toll station terminals in Europe" (Section 4).

Hai cấu hình thời gian giữa hai lần đến:

  • \(1/\lambda = 50\) giây
  • \(1/\lambda = 40\) giây (tải cao hơn)

Với mỗi tổ hợp \((1/\mu_1, 1/\mu_2)\), bài báo tính thời gian chờ trung bình \(W\) (giây) và xác suất bị chặn \(P_b\) từ công thức dạng đóng.

3. Phân tích hiệu ứng hoán đổi server (Server Swap Analysis)

{% include components/box-start.html type="summary" title='Kết luận chính từ kết quả số' %}

Khi hai server có tốc độ phục vụ khác nhau (\(\mu_1 \neq \mu_2\)), đặt server nhanh hơn ở vị trí 2 (cửa cuối) luôn cho kết quả tốt hơn:

  • Thời gian chờ trung bình \(W\) giảm.
  • Xác suất bị chặn \(P_b\) giảm.
{% include components/box-end.html %} {% include components/example-start.html title='Ví dụ: Hoán đổi server (1/μ₁=15, 1/μ₂=50 vs ngược lại)' %}

So sánh hai cấu hình với \(1/\lambda = 50\) giây:

Cấu hình\(W\) (s)\(P_b\)
\(1/\mu_1 = 15\), \(1/\mu_2 = 50\) (S1 nhanh, S2 chậm)85.250.2970
\(1/\mu_1 = 50\), \(1/\mu_2 = 15\) (S1 chậm, S2 nhanh)46.840.0175

Kết quả hoán đổi:

  • \(W\) giảm từ 85.25 → 46.84 giây (giảm 45%).
  • \(P_b\) giảm từ 0.2970 → 0.0175 (giảm 17 lần).

Bài báo ghi nhận: "the sojourn time is 85.2501 seconds for \(1/\mu_1 = 15\) seconds, \(1/\mu_2 = 50\) seconds, \(\lambda = 1/50\) 1/seconds) when there is a big difference between the capability of service persons."

{% include components/example-end.html %}

Hiệu ứng tương tự xuất hiện ở mọi cặp không đối xứng trong Table 2. Ví dụ khác: \((25, 50)\) vs \((50, 25)\) với \(1/\lambda = 50\):

  • \(W\): 94.40 → 69.74 (giảm 26%)
  • \(P_b\): 0.2625 → 0.0541 (giảm 4.8 lần)

4. Ý nghĩa quản lý (Managerial Implications)

Bài báo kết luận (Section 4): "It can be concluded from these results that the sojourn time and the utilization of the first server can be improved if a more skilled person is placed in the second server position of the tollbooth system."

{% include components/box-start.html type="summary" title='Khuyến nghị quản lý' %}

Trong hệ thống tollbooth với hai server, "it is always advised to place a more skilled person in the second server position" (Section 5).

Lý do trực quan: Server 2 là nút thắt cổ chai (bottleneck) của hệ thống. Khi server 2 chậm, hiện tượng blocking xảy ra thường xuyên hơn: server 1 bị chặn, không thể nhận khách mới, hàng đợi dài ra. Đặt người giỏi hơn ở cửa cuối giúp giải phóng hệ thống nhanh hơn, giảm cả thời gian chờ lẫn xác suất bị chặn.
