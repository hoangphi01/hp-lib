linear_scale Hàng đợi tandem

Hai server nối tiếp: khách phải qua server 1 rồi mới đến server 2.

Đặc trưng: không có bộ đệm giữa hai server, rời đôi khi S2 xong + S1 bị chặn.

block Blocking

Khi server 1 hoàn thành nhưng server 2 đang bận, khách bị chặn tại server 1.

Khi S2 xong: 2 khách cùng rời (khách S2 + khách bị chặn). Đây là lý do chuỗi Markov có dạng GI/M/1-type.

swap_horiz Heterogeneous servers

Hai server có tốc độ phục vụ khác nhau: \(\mu_1 \neq \mu_2\).

Kết luận: nên đặt server nhanh ở vị trí 2 (cửa cuối).
